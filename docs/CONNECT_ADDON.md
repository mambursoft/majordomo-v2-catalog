# Описания для Connect

## MQTT v2

Локальный MQTT-мост для MajorDoMo. Валидация идентификаторов, адаптивная форма настроек, локализация en/ru/uk. Архив: https://github.com/mambursoft/majordomo-mqtt-v2/releases/tag/v2.0.0

## Tuya v2

Работа с устройствами Tuya без вызовов Python и exec. Пароль не попадает в HTML, настройки адаптированы для телефонов. Архив: https://github.com/mambursoft/majordomo-tuya-v2/releases/tag/v2.0.0

## Xiaomi miIO v2

Облачное подключение Xiaomi на PHP. Проверка прав AJAX, безопасная генерация ID сообщений через flock. Архив: https://github.com/mambursoft/majordomo-xiaomimiio-v2/releases/tag/v2.0.0

## Google Location v2

Геолокация через Google Family Link и GPS Tracker. Карта, мануал и локализация. Архив: https://github.com/mambursoft/majordomo-google-location-v2/releases/tag/v2.0.0
